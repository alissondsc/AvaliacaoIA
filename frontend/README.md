# AvaliacaoIA frontend

Interface React/TypeScript com Vite e TanStack Start. O catálogo e a criação
de pedidos usam a API Express em `http://localhost:3000/api` por padrão.

```powershell
npm install
npm run dev
```

Para usar outra API, defina `VITE_API_URL` com a URL base, incluindo `/api`.
Consulte o README da raiz para executar o projeto completo.
