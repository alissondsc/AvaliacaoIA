# Prompt para Lovable — BURGUER HOUSE

Crie uma interface web moderna e responsiva para a hamburgueria fictícia
**BURGUER HOUSE**, seguindo um visual editorial e acolhedor. Use fundo branco e
creme, texto preto e laranja como cor de destaque; cartões limpos, cantos
discretos e tipografia forte. Não use imagens externas obrigatórias: prefira
elementos gráficos simples que mantenham o projeto leve.

A página deve incluir cabeçalho com marca e acesso ao carrinho, uma área hero
com chamada para ação, catálogo em cartões e filtros **Todos**,
**Hambúrgueres**, **Porções** e **Bebidas**. Em cada produto, apresente nome,
descrição, categoria, preço e ação para adicionar ao pedido. Mostre o carrinho
com quantidades, controles para aumentar/diminuir/remover, subtotais, total e
ação para finalizar. Após finalizar, exiba número do pedido, produtos,
quantidades e total. Apresente estados de carregamento e mensagens de erro.

Construa uma experiência acessível, com estados de foco visíveis, texto legível
e layout funcional em telas de celular. Os dados devem vir da API existente;
não invente produtos nem valores e não implemente pagamentos.
